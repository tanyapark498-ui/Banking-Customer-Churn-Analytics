## Banking Customer Churn Analytics

Проанализировала данные 80 000 клиентов банка, чтобы выяснить, кто чаще уходит и можно ли заранее определить таких клиентов.

Что сделала

* Проверила данные на пропуски, дубликаты и аномалии.
* Провела EDA: изучила отток по сегментам, возрасту и каналам обслуживания.
* Написала SQL-запросы в PostgreSQL, в том числе с оконными функциями.
* Проверила гипотезы с помощью статистических тестов.
* Построила Logistic Regression и Random Forest, сравнила их качество.
* Собрала дашборд в Tableau.

Что получилось

* Mass — самый проблемный сегмент: отток 39,5%, на него приходится 59% всех уходов.
* Среди клиентов без мобильного приложения отток 21,1%, среди пользователей — 6,5%.
* В группе Mass в возрасте 18–24 лет отток достигает 51%.
* У ушедших клиентов медианный engagement_score ниже: 16 против 25.
* Самый высокий ROC-AUC показала Logistic Regression — 0,857. У Random Forest — 0,855.
* В топ-20% клиентов по прогнозируемому риску фактический отток составляет 50,4% против 18% по всей выборке.

## Вывод

Основное внимание стоит уделить сегменту Mass, особенно молодым клиентам. Также стоит изучить связь между использованием мобильного приложения и оттоком.

Модель позволяет выделить клиентов с повышенным риском ухода для дальнейшей работы с ними.
